# Glossary (Explainer; Mongolian gloss in parentheses)
- (Explainer) **Chiplet**: a small die combined with others in one package. (жижиг чип, багцад нэгтгэнэ)
- (Explainer) **Hybrid bonding**: direct copper-to-copper die bonding at very fine pitch. (шууд зэс-зэс холболт)
- (Explainer) **Flip chip**: die attached face-down with solder bumps. (хөрвүүлж залгах)
- (Explainer) **HBM**: high-bandwidth memory, stacked DRAM beside the processor. (өндөр дамжуулах чадалтай санах ой)
- (Explainer) **OSAT**: outsourced semiconductor assembly and test company. (багцлах, шалгах гэрээт компани)
- (Explainer) **EDA**: software used to design chips. (чип зохиох програм хангамж)
- (Explainer) **RTL**: register-transfer level, the hardware description written before synthesis. (RTL түвшний тодорхойлолт)
- (Explainer) **IP block**: reusable design module. (дахин ашиглах блок)
- (Explainer) **Pitch**: distance between neighbouring connections; smaller means denser. (холболтуудын зай)
- (Explainer) **FP8**: 8-bit floating point format for AI. (8 битийн хөвөх таслалтай тоо)
- (Explainer) **NPU**: neural processing unit, a block for AI inference. (мэдрэлийн сүлжээний процессор)
- (Explainer) **EMIB**: Intel's embedded bridge packaging technology. (Intel-ийн багцлалтын технологи)
- (Explainer) **18A / 2 nm**: marketing names of leading-edge process nodes. (дэвшилтэт процессын түвшин)
- Samsung's hybrid bonding target uses a 6 µm pitch. [SPN-1112-01, 2026-11-12]

- (Explainer) **RDL**: redistribution layer, extra wiring on a package that reroutes die connections. (дахин хуваарилах давхарга)
- (Explainer) **LPDDR5X**: low-power DRAM type used in phones and edge AI chips. (бага чадалтай DRAM)
- (Explainer) **SRAM**: fast on-chip memory built from transistors, takes much area. (хурдан, том талбай)
- (Explainer) **Soft error**: a bit flip caused by radiation such as alpha particles, not by permanent damage. (түр зуурын алдаа)
- (Explainer) **HLS**: high-level synthesis, turning C-like code into RTL. (өндөр түвшний синтез)
- (Explainer) **Sovereign AI**: a country building its own AI computing capacity. (улсын өөрийн AI тооцоолол)
