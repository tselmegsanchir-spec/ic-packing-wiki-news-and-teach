# Memory-aware architecture
- AI inference drives designs that reduce data movement, such as processing-in-memory and near-memory computing. [SPN-1113-02, 2026-11-13]
- Memory capacity, bandwidth, latency, power and cost must be planned together with compute and interconnect. [SPN-1113-09, 2026-11-13]
- Custom HBM base dies can carry customer-specific functions. [SPN-1118-05, 2026-11-18]
- (Explainer) Moving data costs more energy than computing on it, which is why placing logic near memory is attractive.
- Memory cost is now a design constraint: Tesla trimmed the memory of its AI4.5 chip to 24GB. [SPN-1123-02, 2026-11-23]
- New memory proposals such as Z2RAM target AI accelerators with a speed and density mix between SRAM and DRAM. [SPN-1123-06, 2026-11-23]
