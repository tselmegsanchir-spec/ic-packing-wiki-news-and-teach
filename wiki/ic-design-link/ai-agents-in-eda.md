# AI agents in the EDA flow
- Agentic AI coordinates specialized tools and keeps human verification. [SPN-1113-10, 2026-11-13]
- Orchestration, security, data privacy and reliability are prerequisites for more agent autonomy. [SPN-1117-01, 2026-11-17]
- Industry leaders flag integration, expertise retention, proprietary data and cost as challenges. [SPN-1119-10, 2026-11-19]
- (Explainer) EDA = electronic design automation: the software (simulation, synthesis, place-and-route, verification) used to design chips.
- (AI hypothesis) A beginner should still learn RTL and verification basics, since agents are described as supervised by engineers.
